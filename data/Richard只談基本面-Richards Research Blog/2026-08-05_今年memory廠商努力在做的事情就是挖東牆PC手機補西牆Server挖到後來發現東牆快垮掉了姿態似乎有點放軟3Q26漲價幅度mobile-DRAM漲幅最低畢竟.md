# 今年memory廠商努力在做的事情，就是挖東牆(PC/手機)補西牆(Server)，挖到後來發現東牆快垮掉了，姿態似乎有點放軟，3Q26漲價幅度mobile DRAM漲幅最低，畢竟東牆垮掉只有西牆也不行(應用面多元化符合長期利益)，但這樣挖東牆補西牆這條路也走不太下去了，而西牆拿到不少東牆挖來的石頭，還是不夠，只好把城牆預定高度降規(減少content)，關鍵還在於採石場產能不夠，擴產又要時間緩不濟急

今年memory廠商努力在做的事情，就是挖東牆(PC/手機)補西牆(Server)，挖到後來發現東牆快垮掉了，姿態似乎有點放軟，3Q26漲價幅度mobile DRAM漲幅最低，畢竟東牆垮掉只有西牆也不行(應用面多元化符合長期利益)，但這樣挖東牆補西牆這條路也走不太下去了，而西牆拿到不少東牆挖來的石頭，還是不夠，只好把城牆預定高度降規(減少content)，關鍵還在於採石場產能不夠，擴產又要時間緩不濟急
