# Memory module廠毛利率試算

原文連結: https://www.facebook.com/permalink.php?story_fbid=pfbid024v85Yyo5qXF5VGdjLtRxeKqTitcG3umicBJ9fTNZK2DD1QLAF3v4niZpubG9BPc5l&id=100054201473657
Memory module廠毛利率試算

只是試算、概算，一定有假設，各公司策略、做法也一定不同

假設以調研公司公布的漲幅4Q25 +50%(NAND較低)、1Q26 +90%、2Q26 +60%、3Q26 +15%、4Q26 +5%，DRAM和NAND有差異，以DRAM為基準簡單估

3Q25價格100, 4Q25 150, 1Q26 285, 2Q26 456, 3Q26 524, 4Q26 550

假設memory module廠商的毛利率分兩塊，(1)一塊是正常情況下本身製造、品牌、服務、通路、技術創造附加價值的正常毛利率，(2)另一塊是這波supercycle進貨、銷貨時間落差下的價差毛利率，以下是講(2)價差毛利率，價差毛利率各家各季也會不同因為策略差異，只是整體概估

假設庫存兩季，T期銷售的模組是T-2期進貨的顆粒，則各季(2)價差毛利率為:

1Q26 64%, 2Q26 67%, 3Q26 46%, 4Q26 17%，高峰在2Q26

假設庫存一季，T期銷售的模組是T-1期進貨的顆粒，則各季(2)價差毛利率為:

1Q26 47%, 2Q26 38%, 3Q26 13%, 4Q26 5%，高峰在1Q26

也許有人庫存在1~2季之間，有許有人超過3季，依此類推

因為2H26 DRAM/NAND價格漲幅趨緩，2H26(2)價差毛利率將明顯向下，至於公司毛利率，就自己假設普通模組廠(1)正常毛利率10%、純工控模組廠30%、正常/工控mix假設多少，(1)+(2)，一樣，如果(1)是常數，公司毛利率2H26也是要下降

請注意，(1)公司附加價值創造的正常毛利率，長期看，可能逐漸往上或往下，因為公司的技術、產品、品牌、服務價值可能因長期努力提升(或降低)，但我們這裡講的是幾個季度之內、一年內，公司附加價值提升不可能讓下游SMT組裝業毛利率幾季內5%、10%、20%的提升，那是經年累月才有的，所以有些公司把(1)和(2)混為一談，聽者可能要有所區分

DRAM製造廠不一樣，製造廠的成本COGS大致固定或隨製程微縮進步、良率提升而緩慢往下，價格只要上漲，不管漲幅是不是趨緩、不論漲多漲少，毛利率都是提升的
