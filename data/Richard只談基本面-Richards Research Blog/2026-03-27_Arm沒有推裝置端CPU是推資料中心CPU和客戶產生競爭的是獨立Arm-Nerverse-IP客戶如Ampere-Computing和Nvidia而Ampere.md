Arm沒有推裝置端CPU，是推資料中心CPU，和客戶產生競爭的是獨立Arm Nerverse IP客戶如Ampere Computing和Nvidia，而Ampere Computing已經被Arm收購是自己人，只剩Nvidia會競爭但Nvidia也沒其他選擇(Vera自研架構但還是需要Arm指令集授權)，其他Arm Neoverse IP用戶都是CSP ASIC CPU他們沒差，多一個選擇，自研(僅授權Arm IP和指令集)或採購Nvidia或Arm現成CPU

---------'"隨著智能體人工智慧的發展，由數十個模型支援的智能體查詢推理模型的頻率將超過人類使用聊天機器人的15倍，因此人工智慧推理系統需要增加越來越多的CPU。哈斯表示，保守估計，每吉瓦電力至少需要1.2億個核心。隨著核心數量的增加，這可能意味著超過 100 萬個 CPU，而新增的 AI 資料中心容量在 100 吉瓦到 150 吉瓦之間（根據各種估計），這大約相當於 1 億到 1.5 億個 CPU，平均每個 CPU 有 120 個核心。

因此，Arm決定抓住機會、不再猶豫，也就不足為奇了。到2030年，用於智慧體人工智慧系統的CPU市場規模將達到1,000億美元，該公司已向華爾街透露（但昨天參加Arm Everywhere大會的我們卻不知道），到2031年，其AGI CPU產品將帶來150億美元的收入。

這使得Neoverse IP模組和CSS授權的版稅銷售（儘管業績不錯）顯得微不足道。超大規模資料中心和雲端平台建置者不想自己設計CPU和XPU。他們之所以這樣做，是因為他們認為現有供應商的晶片定價過高。由於Arm的晶片與所有自研CPU相容，現在他們可以依靠Arm交付產品——而且，不少科技巨頭很可能會更加依賴AGI CPU，而不是他們自己設計的CPU。

很多事情取決於第一款 AGI CPU 的設計，以及 Arm 路線圖上顯示的後續計畫。

為了快速啟動與 Meta Platforms 的合作項目，Arm 選擇其「Poseidon」V3 核心和「Voyager」CSS V3 平台作為起點，我們曾在 2024 年 2 月詳細介紹過。 Poseidon 核心每個核心配備一對 SVE2 向量單元，因此在處理 AI 工作負載所需的一些運算任務時毫不遜色。

我們之所以這樣稱呼這款名為 AGI CPU-1 的產品（我們目前尚不清楚其代號，以區別於未來的型號），它擁有多達 136 個核心，基於 Armv9.2 指令集。它採用台積電 (TSMC) 的 N3 製程製造，該製程的電晶體尺寸約為 3 奈米，與其他廠商一樣，其實際光罩面積也略大於 800 平方毫米。

這個 136 個核心的數量與 Voyager CSS 模組的原始規格並不完全相符
......
不知道每個核心的L1快取容量，但我們知道每個核心都有2MB的L2緩存，並且核心最高運行頻率為3.7GHz。這些核心沒有睿頻加速模式，也沒有同步多執行緒（SMT）－這兩項技術在x86 CPU都有，而Ampere Computing公司也完全不認同。在Ampere Computing的設計理念中，當試圖從CPU中獲得確定性效能時，這兩項技術都得不償失——而且SMT還會帶來額外的安全漏洞攻擊面。
......
每個插槽都配備了 96 條 PCI-Express 6.0 I/O 通道，這強烈表明 Meta Platforms 所需的 I/O 頻寬將高於 Arm 為 Voyager CSS V3 協定堆疊所設想的水平。這些 I/O 可能透過 DPU 連接到乙太網路交換機，兩者都運行 Meta Platforms 正在推廣（或更確切地說是正在拉取）的 ESUN 記憶體一致性協定。這些 PCI-Express 6.0 插槽也支援必要的記憶體擴展，當然，這會犧牲一些面向外部世界的 I/O 通道。
......
這款136核心AGI CPU-1晶片最令人稱道之處在於：它的熱設計功耗僅300瓦。這著實令人欣喜，也充分展現了Arm為Meta架構打造強大而節能的處理器所做的諸多工程設計。平均每個核心的功耗僅為2.2瓦。

相較之下，一顆128核心的「Granite Rapids」Xeon 6 6980P（採用支援SMT的全性能P核心）運作頻率僅為2GHz，功耗高達500瓦，即每個核心3.9瓦。而一顆144核心的「Sierra Forest」Xeon 6（採用不支援SMT的節能核心）運作頻率為2.2GHz，功耗則高達330瓦，即每個核心2.3瓦。我們目前尚不清楚運行頻率為3.7GHz的V3核心的性能，但我們強烈懷疑它的性能遠超Sierra Forest的E核心，並且考慮到其2.85倍的更高時脈頻率，其性能應該也優於Granite Rapids的P核心。
......

AGI CPU 的目標是讓大型企業和沒有自己晶片設計團隊的公司能夠使用 Arm 伺服器 CPU，同時也為自行設計晶片的使用者提供另一種選擇。正如在一個健康的 x86 生態系統中，AMD 為客戶提供了一個可以取代 Intel 的可靠選擇。"
