1. Hyperscaler大量布建ASIC/XPU Server算力，XPU也需要CPU，2025年XPU Server以x86為主，Arm-based CPU只佔25%，根據Counterpoint 2029年將大幅躍升到90%

2. Arm based CPU未來分三種，第一傳統使用Arm標準IP自行設計CPU ASIC包含Google Axion, Microsoft Azure Cobalt, AWS Graviton, Nvidia Grace，第二使用Arm AGI CPU完成品(Meta等)，第三為使用Nvidia只授權Arm指令集自研的Vera CPU(Meta)

3.據了解，Arm-based CPU收取(1)每一次新CPU IP架構如Nerverse V3收取一次性授權金lincense, (2)每顆出貨量收取權利金(royalty)，這個是按核心數收費，所以每一顆Server CPU除了Nerverse權利金本高之外，每顆CPU幾十上百核心cores是以cores數字收費, (3)Arm v9xx等的指令集授權金，Apple手機AP和Nvidia Vera屬於這種，要使用Arm指令集才能用Arm相容軟體生態系

4. 目前的XPU Server的CPU:XPU配比偏低(1:4或1:8或更低)，因為兩年前設計Arm based CPU + XPU Server的時候AI Agent還沒有爆紅，未來因應AI Agent CPU+XPU雙引擎需求，預期長線CPU:XPU的配比將提升CPU比重向Nvidia的1:2看齊

5. 我們常用的3M分析
ARM、ASIC/XPU Server市場的CPU
(1) Market size大幅成長(Server CPU市場)
(2) Market share大幅成長(取代x86)
(3) Margin不一定，有機會上升因為Server CPU IP比重提升(相對手機AP和MCU IP)，但是AGI CPU是半導體成品不是IP毛利率會降低但是總毛利金額成長，讓margin上或下不一定

3M都上升是少數中的少數(循環型產業除外)，2M上1M平(內涵毛利金額還是上升)這樣的組合也相當不錯了

----------"Arm 架構 CPU 預計於 2029 年前佔據 AI ASIC 伺服器 CPU 市場 90% 份額
......
預計到 2029 年初，Arm 架構將主導 AI ASIC 伺服器 CPU 市場，這得益於兩大強大推動因素——對 Arm 架構授權的積極擴展，針對專有超擴展器內部 CPU 晶片，以及交鑰匙的 Arm AGI CPU 平台的推出。

Arm 以 AGI CPU 進軍資料中心 CPU 市場，Meta 為主要客戶之一，進一步證明了從商用 x86 基礎 CPU 在成長中的超大規模半客製化 AI 基礎設施中結構性轉變。
......
過去三年，基於 x86 的 CPU 在 AI 基礎設施加速器部署的 CPU 附加率中佔據主導地位。領先的超大規模企業一直依賴 Intel 和 AMD 處理器作為其 ASIC 伺服器部署的主機 CPU  ，反映出軟體相容性需求及現有資料中心基礎設施。然而，在這個成長的市場中，由於需要由半客製化 AI 加速器或 XPU 驅動的異質架構，我們看到基於 Arm Neoverse 核心的 Arm 伺服器 CPU 採用的推動力更大。
......
專有的 Arm CPU 最初主要用於通用雲端工作負載，後來才被設計用於 AI 伺服器程式。基於 Arm 的 CPU 已展現出比同類 x86 機架配置高出兩倍的每瓦效能，這對於超大規模開發者在固定功耗範圍內最大化運算密度至關重要。

研究助理 David Wu 強調這一趨勢  ：「雖然 x86 架構目前在 AI 伺服器基礎設施中仍佔有重要地位，但我們的世代分析顯示，這個穩固的據點正迅速轉向專有的 Arm 架構設計。我們預期2026年下半年這一轉變將有更明顯的加速。
......
對 Google 而言，其基於 Axion Arm 的 CPU 在下一代 TPU 基礎設施中逐步升級，是此次轉型中最重要的單一事件，顯示基於 Arm 的 CPU 已準備好大規模部署 AI 基礎設施。

AWS 也在跨越世代的 Trainium 中調整策略，Arm 架構的 Graviton 處理器在高密度配置中扮演越來越重要的角色，儘管 x86 仍以向後相容性為由部署。

除了 Google 和 AWS，Arm  轉型在超大規模市場中也逐漸受到關注。Microsoft 從一開始就將其 Azure Cobalt ARM CPU 與 Maia AI 加速器家族搭配使用。

這時，Arm AGI CPU 登場

Meta 最近確認 Arm 為其下一代 MTIA 基礎設施的策略 CPU 合作夥伴，並將 Meta 列為 Arm 首款 AGI CPU 的首發客戶，進一步顯示從商用 x86 轉型是業界深思熟慮的方向，而非孤立的設計決策。
......
超大規模企業根據自身部署需求做出有意識的選擇，撰寫相容且互通的軟體，經濟效益令人振奮。預計轉型將於 2026 年下半年大幅加速，主要推動者是自家 Arm CPU 與下一代 ASIC 平台在主要超大規模業者的廣泛部署。」
......
Shah 補充說：「我們的分析預測，到   2029 年，基於 Arm 的 CPU 將佔客製化 AI ASIC 伺服器主機 CPU 部署的至少 90%，較 2025 年的約 25% 有所提升，這是由於 Arm CPU 計畫在主要超大規模企業加速推廣所推動的結構性轉變。」"
