2023年AI Server需求開始爆發以來，新型態AI Server ODM的毛利率總是讓人關心+擔心，當時很合理，因為AI Server比general Server價格貴20X，營收大增之下，低毛利率的ODM產業到底能賺多少錢不好估計，2024年開始AI Server從8卡GPU的HGX NVL8，大幅改架構為72顆GPU一櫃的GB NVL72，出售單位從Server box大改為Rack，價格又貴了很多倍，營收大增之下，低毛利率的ODM產業到底能賺多少錢不好估計，關心+擔心，還是很應該，2025~2026年GB200到GB300陸續量產，AI Server ODM財報出來連續多季獲利都不錯，確實有賺到錢，2H26 Oberon NVL72架構大方向，繼續沿用到Rubin VR200 NVL72，同樣的BOM"結構"(BOM當然不一樣是說大結構)，同樣的議價標案和議價方法，總獲利或毛利金額的能見度、掌握度，和2023、2024年相比，理應大幅提升，但因為是低毛利率產業，"毛利率展望"，還是讓人擔心.......其實有幾點已經不同

1. Oberon機架大架構從Blackwell、Blackwell Ultra、Rubin、Rubin Ultra將沿用四代六年，到2028年量產的Rubin Ultra還是主力架構，細部每代都有改，大架構沒變，設計/研發/工程，ODM無論是報價經驗、成本經驗，已經比第一代掌握度高很多，有過去實績可參考，"毛利金額"、"總獲利"的風險大為降低

2. 今年關心的波動是重要零件的Buy and Sell或Consign的差異，這種波動是 "營收" 和 "毛利率" 的蹺蹺板，對 "毛利金額" 影響不大，從Buy and Sell改為Consign的零件越多(memory、GPU......)，營收越低但毛利率越高，反之亦然，但毛利金額差異不大，也就是說，今年的風險是 "財務報表"長相的風險，不是"毛利金額"或"總獲利"或EPS的風險，這種風險，其實不是風險，也不需要花太多時間研究，因為不大影響總獲利，同樣是變動，1和2同樣是風險，意義大不同

估計毛利率的目的是計算 "毛利金額"，營收、ASP、毛利率，相對難估，但是 "毛利金額" 相對好掌握的時候，就不用太拘泥在拆解營收和毛利率、拘泥在Excel earnings model的蹺蹺板了

3. 今年AI Server ODM整體產業毛利金額、總獲利、扣除B&S/or/Consign變動後的利潤率，主要受到五力分析中(A)客戶議價力、(B)同業競爭壓力兩項因素影響，目前的狀況，大型AI Server ODM還是原來那幾家，有一兩家小廠擠進來但整體供應能力無法等量放大，(1)AI Server ODM家數不多、(2)總體產能、供應能力受到北美建廠、工廠工程能力等因素趕不上市場成長，(3)最重要的RD人力資源/RD工程師產能，又趕不上前項生產產能，開案、改案、客製化數量無法等比成長，(4)客戶端除了原有hyperscaler之外，又多了許多放量的Neocloud，這些新Hyperscaler(如xAI)和新Neocloud，硬體工程實力遠不如傳統四大五大Hyperscaler，更依賴AI Sever ODM，因為(1)(2)(3)(4)今年的獲利率相對穩定、相對可預測

4. Rubin大架構HGX和Oberon不變， Rubin Ultra也以Oberon為主力，設計一定有改變，是說報價和成本經驗不變，相對2023從general server到AI server和2024從HGX到NVL72 Rack而言，變化少很多，利潤的掌握度，可以延長到2028年，是有AI Server爆發以來架構對獲利能影響，的能見度最遠的時刻，當然如果AI泡沫爆掉整體market/unit/shipments跟著爆就不用講獲利了(至少組裝業低折舊不會變虧)

5. 毛利率、獲利率高低，其實受到產業型態影響很大，高資本支出、資本密集業、組裝業、研發+組裝業、買賣業，利潤率一定差很多，所以才有杜邦分析，將ROE分為(1)利潤率(2)週轉(3)槓桿三個來源，AI Server ODM和PC ODM這種電子組裝業，相對上游產業，更加依賴(2)週轉和(3)槓桿來創造ROE，並非低毛利率的產業、公司就一定不好

6. 撇開營收、毛利率、Buy and Sell等干擾，把剛發布的1H26毛利金額，對比AI Server剛剛發生的1H23毛利金額，三年下來，華碩成長為3X、技嘉成長為4X、緯創成長為3X、緯穎成長為4X、廣達成長為2.4X、鴻海成長為1.6X(鴻海較低因為還有龐大的Non-AI業務)
