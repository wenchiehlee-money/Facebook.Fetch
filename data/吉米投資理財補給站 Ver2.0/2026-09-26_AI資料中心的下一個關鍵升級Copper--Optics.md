# 🔥 AI資料中心的下一個關鍵升級：Copper → Optics

原文連結: https://www.facebook.com/reel/2195886624290559/
🔥 AI資料中心的下一個關鍵升級：Copper → Optics
▪️ Marvell高層：AI正在逼著互連從Copper走向Optics
Marvell 兩位高階主管 Dave Lazovsky（資料中心網路事業）與 Will Chu（Custom Cloud Solutions） 最近談到 AI 基礎建設的變化。他們認為，隨著 AI 模型與 XPU 規模持續放大，傳統 Copper 在距離、頻寬與功耗上的限制會越來越明顯，光互連的重要性正在快速提升。

⚡ 最值得注意的是功耗
Lazovsky 提到，Marvell 的 Analog SerDes 搭配光互連方案，可以讓光鏈路功耗相較傳統方案大幅降低；Marvell 更估計，如果大規模部署，整體資料中心功耗有機會降低超過 25%。

這是 Marvell 自己提出的技術觀點與估算，並不是已經被整個產業驗證的結果。但方向很值得注意，因為 AI 資料中心未來最大的瓶頸之一，可能不只是 GPU，而是電力與散熱。

🔹 MRVL不只是做ASIC
市場容易把 Marvell 看成 ASIC／XPU 公司，但兩位主管強調，Marvell 還能從 XPU 周邊的多個環節切入，包括 SerDes、Switch、CPO、NPO、CXL 與記憶體相關技術。

隨著 AI 叢集規模持續放大，每顆 XPU 周圍需要的高速互連與記憶體相關元件也會增加，這讓 Marvell 有機會從單一晶片，進一步吃到整個 AI 基礎架構的價值。

🧠 Memory Wall也正在推動高速互連
AI 推理與 KV Cache 持續增加，記憶體容量與頻寬需求越來越高，因此 HBM、CXL、Memory Expansion、Disaggregated Memory 等架構開始受到重視。

而這些技術都有一個共同點：
需要更多高速 IO 與互連。

📌觀察
AI 資料中心正在從單純的「算力競賽」，進入算力＋記憶體＋互連＋電力效率的全面競爭。

對 MRVL 來說，真正值得追蹤的是 Copper → Optics、SerDes → CPO/NPO，以及 Memory Wall 所帶來的高速互連需求。
