# 🔥 台灣CPU供應鏈廠商

原文連結: https://www.facebook.com/reel/1298843382268889/
🔥 台灣CPU供應鏈廠商
▪️上游：晶圓製造
TSMC 台積電｜2330
全球最大晶圓代工廠。
負責把 CPU、GPU、ASIC 等晶片「做出來」。
現在重點已經不只是先進製程，還包括 CoWoS、SoIC 等先進封裝。
AI/HPC 是目前非常重要的需求來源。2025 年先進製程（7nm以下）已占台積電晶圓營收 74%。
👉 一句話：CPU/GPU 的「晶片製造者」。

⚡ 封裝基板／IC載板
LOTES 嘉澤｜3533
主要做 連接器、Socket、Cable Assembly。
CPU Socket 是它很重要的產品之一。
CPU 插在主機板上，需要 Socket 把 CPU 與 PCB 電性連接起來。
👉 CPU 與主機板之間的「插座」。

Unimicron 欣興｜3037
台灣重要 PCB／IC 載板廠。
做 ABF載板、HDI、高階PCB 等。
CPU、GPU、AI ASIC 等高階晶片都會用到高階封裝基板。
👉 晶片下面承載晶片、把訊號往外傳的「高階基板」。

Kinsus 景碩｜3189
核心也是 IC載板。
ABF 載板是市場關注重點之一。
CPU／GPU／ASIC 等高階晶片封裝，都會需要高階載板。
👉 和欣興同屬「IC載板」核心供應商。

Nan Ya PCB 南亞電路板｜8046
PCB＋IC載板。
背後有南亞／台塑體系的材料與製造資源。
AI伺服器、高速運算帶動高階 PCB、載板需求。
👉 「PCB＋載板」雙重角色。

🧪 封裝／測試
ASEH 日月光投控｜3711
全球大型半導體封裝測試業者。
做 封裝、測試、組裝。
台積電把晶圓做出來之後，後面的封裝與測試就是重要環節。
👉 晶片「加工、封裝、驗貨」的人。

而且現在 AI 晶片越來越複雜，先進封裝的重要性持續提高，台積電本身也在大幅擴充先進封裝能力。

PTI 力成｜6239
半導體封裝測試廠。
主要從事 IC 封裝與測試。
記憶體相關封裝測試尤其重要，也延伸到邏輯 IC 等。
👉 也是「後段封裝測試」玩家。

🖥️ 伺服器／AI Server
這一區就不是在「做 CPU」，而是把 CPU、GPU、記憶體、網路晶片等東西 組成完整伺服器。

Wiwynn 緯穎｜6669
專攻 雲端資料中心伺服器與機櫃系統。
客戶以大型雲端服務商／Hyperscaler 為主。
AI Server、Cloud Server 是核心成長方向。
👉 「資料中心伺服器製造商」。

GIGABYTE 技嘉｜2376
不只是消費型 PC。
現在也做 伺服器、AI Server、主機板、GPU相關硬體。
AI 資料中心需求提高後，伺服器業務的重要性明顯提升。
👉 「PC＋伺服器＋AI硬體」。

Inventec 英業達｜2356
主要做 伺服器、筆電、網通設備等 ODM。
雲端資料中心與 AI Server 是重要業務。
👉 「幫品牌／雲端客戶把伺服器做出來」。

QCT / Quanta 廣達｜2382
Quanta 是母公司，QCT（Quanta Cloud Technology） 是其雲端伺服器品牌／事業。
主要做 Cloud Server、AI Server、Rack 等。
是台灣非常重要的 AI Server ODM。
👉 「大型資料中心伺服器 ODM」。

Wistron 緯創｜3231
ODM 大廠。
原本筆電、PC、企業產品就很強，現在也積極布局 AI Server、資料中心。
與雲端服務商的伺服器需求高度相關。
👉 「PC ODM → AI Server ODM」。

AIC 宜鼎／艾訊這類伺服器相關公司｜3693
這裡要特別注意：3693 是營邦（AIC）。
主要做 企業級儲存、伺服器、機架式系統、AI/HPC相關設備。
規模比廣達、緯創這類 ODM 小，但更偏企業伺服器／儲存系統。
👉 「企業伺服器＋儲存設備」。
