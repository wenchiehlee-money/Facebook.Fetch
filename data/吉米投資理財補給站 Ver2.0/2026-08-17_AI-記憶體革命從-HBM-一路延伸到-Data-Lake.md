🧠 AI 記憶體革命：從 HBM 一路延伸到 Data Lake
🚀 ① Near Memory：AI 算力最直接的記憶體需求
這一層的核心就是 HBM，也是目前 AI 伺服器最關鍵的高頻寬記憶體。輝達 GPU 的運算能力越來越強，對 HBM 的容量、頻寬與功耗效率要求也同步提升，因此 SK hynix、Samsung、Micron（$MU） 都是最直接的受惠者。

真正值得注意的是，AI GPU 從 HBM3E 走向 HBM4 後，記憶體的重要性只會越來越高。HBM 已經不是單純的「配件」，而是 AI 加速器效能能否充分發揮的核心元件。

🖥️ ② Main Memory：AI Server 的 DRAM 需求同步增加
除了 GPU 使用 HBM，AI Server 裡面的 CPU、網路與其他運算元件仍然需要大量 DDR5 / DDR6 DRAM，因此 AI 伺服器擴張也會推升傳統 DRAM 的需求。

這一層主要就是 SK hynix、Samsung、Micron，另外 CXMT（長鑫存儲） 也正在擴大 DRAM 的產能與技術能力。

換句話說，AI 帶來的並不是只有 HBM 成長，而是 HBM + Server DRAM 同時升級。

🔗 ③ Expansion Memory：CXL 開始變得重要
當 AI 模型越來越大，單靠 CPU 旁邊的傳統 DRAM 已經不一定足夠，因此 CXL（Compute Express Link） 的角色開始浮現。

CXL 可以讓 CPU 更有效率地連接額外記憶體，形成「Memory Expansion」，讓伺服器能夠在不單純增加 CPU 本地 DRAM 的情況下，擴充可使用的記憶體容量。

因此這一層值得注意的反而不是傳統記憶體製造商，而是 Astera Labs（$ALAB）、Marvell（$MRVL）、Microchip（$MCHP）、Rambus（$RMBS） 這類高速互連、Memory Interface 與 CXL 相關公司。

📌 這是一個很重要的轉變：AI Memory 的價值開始從「記憶體顆粒」延伸到「如何把更多記憶體接進系統」。

💾 ④ Contexted Memory：AI 開始需要更大的「上下文記憶」
AI 模型規模不斷增加，除了高速 HBM 之外，也需要大量 SSD、NAND Flash 儲存模型權重、Embedding、資料集、KV Cache 與推論資料。

因此這一層開始連結 Kioxia、Micron、SK hynix、Samsung、WDC、SanDisk（$SNDK）以及 Silicon Motion（$SIMO）。

其中 SIMO 特別值得觀察，因為它不是 NAND 製造商，而是做 SSD Controller。當 AI Data Center 對高效能 SSD 的需求增加時，真正需要升級的不只是 NAND，也包括控制器、韌體與資料傳輸效率。

🌊 ⑤ Data Lakes：AI 最終還是需要「海量低成本儲存」
AI 訓練資料、模型 Checkpoint、影像、影片、Log、Sensor Data 等資料量會非常龐大，不可能全部放在昂貴的 HBM 或 DRAM 裡，因此最後仍然需要大量 SSD、HDD 與 Enterprise Storage。

這也是 Seagate（$STX）、WDC、Dell（$DELL）、NetApp（$NTAP）、Pure Storage（$P）、HPE、IBM 所處的位置。

其中 STX / WDC 更偏向大容量儲存；DELL / HPE / NTAP / Pure Storage / IBM 則更接近企業級 Storage Infrastructure 與 Data Management。

🔥 真正值得看的，是「整條 Memory Hierarchy」
AI 帶來的並不是單一 HBM 需求，而是一條完整的記憶體與儲存階層都在升級：
HBM → DRAM → CXL Memory → SSD / NAND → HDD / Data Lake

越靠近 GPU，重點是 頻寬與延遲；越往後，重點則逐漸變成 容量與每 TB 成本。

因此，AI 越強，並不代表只有 HBM 廠商受惠。當模型越大、Context 越長、資料量越龐大，Memory、Interconnect、SSD、HDD、Enterprise Storage 都會被一起拉動。

📌觀察
▪ SK hynix / Samsung / MU：最直接的 HBM + DRAM 核心。
▪ ALAB / MRVL / MCHP / RMBS：吃的是 Memory Expansion、CXL 與高速互連。
▪ SNDK / WDC / Kioxia / SIMO：受惠於 AI SSD、NAND 與高容量資料需求。
▪ STX / DELL / NTAP / PSTG / HPE / IBM：更偏向 AI 時代的海量資料儲存。

⭐ 如果把 AI Infrastructure 看成一棟大樓，HBM 是高速工作區、DRAM 是主記憶體、CXL 是擴建工程、SSD 是資料倉庫，而 Data Lake 則是整座城市的資料庫。
