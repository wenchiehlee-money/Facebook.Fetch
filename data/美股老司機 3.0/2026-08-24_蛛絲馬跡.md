CBRS  創始人兼 CEO Andrew Feldman:

“Cerebras 現已為 OpenAI API 的全新服務層級Ultrafast  提供算力支持，該服務運行 GPT-5.6 Sol 模型，輸出速度高達每秒 750 個 token。

這在速度與智慧的性能前沿開啟了一個全新的維度。

企業現在能夠以即時速度，利用頂尖智慧能力進行開發與建置。

能夠與開發者協同迭代的程式設計智能體。

能在數秒內完成資訊分析與綜合的研究系統。

無需用戶等待即可進行推理，行動與回應的企業級智能體。

當智慧的運行速度達到這個水平，它將徹底改變你能打造的產品形態與使用者體驗。

GPT-5.6 Sol Ultrafast 現已開啟有限範圍的 API 預覽，預計後續將逐步提升容量。”

- - - 

Cerebras 的解法採用其第三代 Wafer-Scale Engine (WSE) 晶圓級晶片。

整張晶圓級晶片直接整合了高達 44 GB 的超高速 SRAM 記憶體，使 GPT-5.6 Sol 的模型權重能夠完全保留在晶片內部，消除對外部記憶體存取的延遲，從而實現了 750 tokens/sec 的極致輸出。

OpenAI 預計將在 2028 年前陸續部署高達 750 MW 的 Cerebras 低延遲推理產能，顯示未來前沿模型推理將朝向通用 GPU + 專用 ASIC/晶圓級晶片混合部署的新形態發展。
