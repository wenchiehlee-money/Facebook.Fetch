# 有用的工具

原文連結: https://www.facebook.com/permalink.php?story_fbid=pfbid02CwagHa9kdBLaVhVAAxcsEb1XuBArAKV9LwWuPhSqqP55EyToL1gfKj3w5aCwdqDvl&id=61564607679559
有用的工具

底下這 5 個網站的基礎功能全部免費，但部分網站(WhaleWisdom.com)  針對進階功能如回測，歷史數據下載設有付費方案：

- Dataroma.com：介面極簡，所有資料直接免費公開。

主要功能：追蹤著名大師持股
專注整理巴菲特，李錄，單井等約 80 位知名價值投資大師的持倉。介面乾淨無廣告，能快速查看大師們共同加碼或重倉的股票。

- CapitolTrades.com：追蹤國會議員交易，無付費牆。

主要功能：追蹤美國政客股票交易
依據美國  STOCK Act  法案，即時整理參眾兩院國會議員及其家屬的股票買賣，適合觀察法案通過前夕的政客資金走向。

- OpenInsider.com：搜尋與查看內部人交易完全免費。

主要功能：追蹤公司高管與內部人買賣
資料同步自 SEC Form 4 申報。可自訂篩選 CEO，CFO 自掏腰包大買自家股票的紀錄，是判斷公司內部看好程度的重要指標。

- 13F.info：免註冊且完全免費，快速查詢 13F 機構持倉。

主要功能：將 13F 機構申報閱讀化
將原本繁雜難讀的 SEC EDGAR 原始文件轉化為直覺表格。載入速度快，能一眼看懂某基金本季相較於上季的加減碼變化。

- WhaleWisdom.com：免費版提供基本的 13F 申報查詢與前十大持股。若需要完整的歷史回測，自訂篩選器或 API 導出數據，則需訂閱付費版。（但免費版已夠用）

主要功能：追蹤機構與對衝基金交易
涵蓋上千家對衝基金與機構的 13F，13D/G 申報。提供持股集中度，換手率分析及熱門買超榜，功能極為全面。
