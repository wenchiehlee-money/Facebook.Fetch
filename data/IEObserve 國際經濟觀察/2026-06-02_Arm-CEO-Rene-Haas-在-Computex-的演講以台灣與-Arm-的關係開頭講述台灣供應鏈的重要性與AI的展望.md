Arm CEO Rene Haas 在 Computex 的演講，以台灣與 Arm 的關係開頭，講述台灣供應鏈的重要性與AI的展望。

從 1993 年第一顆 Arm 晶片在台灣設計算起，已超過三十年。Arm CEO Rene Haas 在 Computex 主題演講中說：「Arm 少了台灣的夥伴什麼都不是。台灣建立了 Arm。」他表示，迄今 Arm 與台灣合作夥伴共同生產了約 2500 億顆晶片，超過全球其他任何地區。

台灣與 Arm：三十年共同成長
Haas 說，Arm 成立於 1990 年，不久之後便與台灣展開合作。他第一次參加 Computex 大約是 2004 或 2005 年，至今已逾二十年。

到了今天，Arm 所有的伺服器 CPU 都在台灣生產，累計與台灣合作夥伴共同生產了約 2500 億顆晶片。Haas 說：「這個數字超過全球其他任何地區。」

他點名台灣生態系支撐的產品涵蓋範圍極廣：Amazon Echo 等邊緣裝置、Oppo 和 vivo 手機、Apple MacBook、Meta Ray-Ban 智慧眼鏡，以及 Tesla、Figure 等廠商的人形機器人所搭載的晶片，連雲端 AI 的 Nvidia 機架和 AWS Graviton，也全部在台灣生態系中製造。Haas 說：「每一樣，100% 都在台灣建造。少了台灣，真的就沒有 Arm。」

Arm AGI CPU：台灣製造、台灣夥伴出貨
Arm 自行設計的伺服器級 CPU，100% 在台灣由 TSMC 製造，目前已進入量產。Haas 強調，Arm 刻意等到產品出貨、客戶到位、生態系夥伴完備之後，才對外公開這款產品。

「我們明白，在這個世界裡，光是交出一顆晶片還不夠，必須連同夥伴一起交付完整的系統。我們與地球上最優秀的夥伴合作，他們全都在台灣。」

他提到展場外的展示區已有完整機架亮相，合作的台灣廠商包括 ASRock、Quanta、Super Micro、Speedy，以及封裝測試夥伴。

產品提供兩種規格：氣冷機架版本有 8000 顆核心、36 kW；液冷機架版本超過 4 萬 5000 顆核心、200 kW。對比同等 x86 系統，Magi CPU 可在相同功耗下提供兩倍效能，估計可為大型資料中心節省超過 100 億美元的能源成本。

#Agent時代的CPU需求爆發
Haas 解釋 CPU 需求爆發的邏輯：「GPU 擅長產生 token，那是它的本職。但 agent 不像人類需要睡覺，agent 會不斷衍生新的 agent。所有這些 token 的分配、管理、編排、傳遞，只有 CPU 能承擔。」

Snowflake、Salesforce、ServiceNow 等 SaaS 公司正在大量部署後端 agent，Anthropic 的 Claude Code 和 OpenAI 的 Codex 也在快速普及。Haas 在三月時提出「未來五年 CPU TAM 將超過 1200 億美元」的預估，當時引發不少質疑，但他說：「現在外界討論的數字幾乎是當初的兩倍。」

Nvidia DGX Spark：Arm 與台灣生態系的結晶
Nvidia CEO Jensen Huang 登台，與 Haas 共同介紹 DGX Spark。這款產品搭載 20 核心的 Arm 架構 Grace CPU，配合 Blackwell GPU，提供 1 petaFLOPS 的 FP4 算力，記憶體達 120 GB，原生支援 Windows on Arm。

Jensen 說明為何選用 Arm：「agent 系統需要優秀的 CPU，需要出色的單執行緒效能。要整合 CPU 並讓它完全配合電腦的形態，Arm 是唯一的選擇。」

這款產品的 SoC 由 MediaTek 負責整合，Arm 透過 CSS（計算子系統）策略提供完整的 CPU、GPU、系統 IP 和記憶體控制器等建構模組。支援出貨的台灣及全球合作夥伴包括 Acer、Asus、Dell、Gigabyte、HP、Lenovo、Microsoft、MSI。

#運算需求的規模與台灣的角色
Jensen 解釋當前 AI 算力需求爆發的根本原因：「過去電腦產業的規模，受限於使用電腦的人數。現在 agent 會自主使用電腦，我們不再只有 10 億人在用電腦，而是有數百億個 agent、機器人、自動駕駛車輛在用電腦。」他預估目前一兆美元規模的電腦產業，最終可能成長至十倍。

對話中也談到 Nvidia 嘗試收購 Arm 一事。Jensen 說：「我很羨慕 Arm 的 IP 供應鏈，因為它的供應鏈是電子，你要用多少就有多少。」Haas 隨即接嘴：「Rene 和我曾經共事，後來我們試著再度合作，只是方式不同。」Jensen 笑道：「我還是有點難過。」

#結語
Haas 以台灣作為整場演講的收尾：「一個平台，從雲端到邊緣。但這一切都不可能發生，少了台灣的合作與付出就不會有今天。再次感謝台灣，感謝這裡的生態系、人才、工程師，和供應鏈管理者。Arm 少了台灣什麼都不是。」
