NVIDIA 在 GTC Taipei 發表全新 RTX Spark 超級晶片，將 Windows PC 重新定義為個人 AI Agent 時代的運算平台，把電腦從工具推向協作夥伴的角色。

執行長黃仁勳指出，過去四十年使用者透過點擊與輸入啟動應用程式，而在 RTX Spark 與 Windows 上，使用者只要提出需求，電腦便會自行完成工作。

#超級晶片架構
RTX Spark 核心採用 NVIDIA Blackwell RTX GPU，配置 6,144 個 CUDA 核心與支援 FP4 精度的第五代 Tensor Core，透過 NVLink-C2C 晶片間互連技術連接 20 核心的 Grace CPU。Arm 架構系統單晶片市場領導者聯發科參與客製化 CPU 設計，貢獻同級最佳的能效、效能與連結能力。

整體平台提供 1 petaflop 的 AI 效能、業界領先的每瓦效能，並搭載最高 128GB 統一記憶體。

#個人Agent平台
AI Agent 已達到關鍵轉折點，OpenClaw、Hermes Agent 等開源專案在 GitHub 與 OpenRouter 等開發者網路創下紀錄，但無法在使用者主要 PC 上安全且私密地執行，限制了普及。

NVIDIA 與微軟合作解決此問題，基礎是全新的 Windows 安全原語與 NVIDIA OpenShell 執行環境，確保代理在使用者完全掌控下安全運作。

OpenShell 讓使用者定義代理可做與不可做的事，依隱私政策智慧路由查詢至本地模型，並在送往雲端模型的查詢中隱藏個人資訊。微軟董事長兼執行長納德拉表示，目標是透過 Windows 將無限制的智慧帶到每個家庭與每張辦公桌，而 RTX Spark 是邁向此願景的真正突破。

#裝置與供應
RTX Spark 筆電最薄達 14 毫米、最輕約三磅，提供 14 至 16 吋機型，採用精密加工鋁合金機身與具備 G-SYNC 技術的色彩精準雙層 OLED 顯示器。

微軟同步推出 Surface Laptop Ultra，並將協作延伸至 NVIDIA DGX Station for Windows，把 Blackwell 架構擴展至企業開發者，將執行代理的 AI 超級電腦帶到桌邊。

RTX Spark 筆電與小型桌機將於今年秋季由華碩、戴爾、HP、聯想、微軟 Surface 與微星推出，宏碁與技嘉的機型隨後跟進。
