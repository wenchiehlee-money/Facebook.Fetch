Arm  創下歷史新高的單季營運表現，單季營收達到 14.4億美元，年增 27%，連續五個季度營收成長超過 20%。授權與其他營收達到 7.73億美元，年增 50%；權利金營收達到 6.7億美元，年增 8%，其中資料中心權利金營收較去年同期翻倍。EPS 年增 33% 達到 0.52美元。

#雙成長引擎啟動：IP授權與自研晶片業務並進
Arm 目前的營運由兩大快速成長的領域所推動，分別是長期的 IP 授權業務，以及全新開展的晶片業務。

Rene Haas 表示：「今日我們的業務由兩個快速成長的領域驅動：一個是合作夥伴持續加碼投資 Arm Compute Platform 並部署創紀錄數量的 Arm 架構晶片的 IP 業務；另一個則是市場對 Arm AGI CPU 需求極為強勁的全新晶片業務。兩者皆運用相同的 Arm Compute Platform 與軟體生態系。」

這兩大成長引擎在資料中心發揮了相互強化的效益。以 Oracle Cloud Infrastructure（OCI）為例，OCI 不僅提供基於 Arm 架構的 NVIDIA Vera CPU，更規劃於 2027 年提供 Arm AGI CPU 執行個體。

#Arm AGI CPU需求激增：兩年累計營收預期上調至20億美元
自今年三月發表 Arm AGI CPU 以來，客戶對該晶片的需求持續增長，主要來自 agent 相關運算架構對 CPU 效能的高度依賴。

Rene Haas 指出：「市場對 Arm AGI CPU 的需求極其強勁，主要是受到我們在 agent 工作負載中所見的一切所驅動，而 CPU 正是其中的核心。現在的需求比我們在三月舉行 Arm Everywhere 活動時更加強勁，來自多家客戶的需求也超出我們先前的預期。」

財務長 Jason Child 說明，公司已取得多家客戶延續至 2027 年底的採購訂單，首批商業交付正按進度預計於 2027 會計年度第四季啟動。

Jason Child 表示：「上一季我們提到對 2027 與 2028 會計年度達成超過 10億美元營收抱持更高信心。在過去 90 天內，我們簽署了來自多家客戶的採購訂單，並與供應鏈夥伴簽署供應協議，這讓我們對在 2027 與 2028 會計年度達成高達 20億美元營收的信心大幅提升。」

針對自研晶片的毛利率表現，Jason Child 補充：「針對第一代產品，我們預期毛利率大約落在 30% 後段至 40% 初期的區間。隨著我們累積更多專業技術，未來可能會承擔更多自主工作，毛利率將逐漸朝向業界標準的 50% 以上邁進。」

#資料中心市占攀升與電力效益優勢
隨著 AI 算力規模擴大，資料中心的電力供應成為關鍵限制。摩根士丹利預估到 2028 年全球資料中心將面臨 38 GW 的電力缺口。

在開放運算計畫（OCP）全球峰會上，第三方機構 Signal65 的獨立測試顯示，Arm AGI CPU 每個機架的運算效能約為 AMD EPYC 9755 的兩倍。Rene Haas 指出：「這種改進幅度可能使預估的全球電力缺口減少一半。」

在市場採用方面，頂級雲端服務商的 Arm 架構伺服器市占率從 2024 年的 15% 增加至 2025 年的超過 50%。隨著 Google Axion、AWS Graviton、Microsoft Cobalt 以及 NVIDIA 等平台的加速部署，Arm 預計該市占率將在 2026 年底前突破 60%。此外，連接加速器的頭節點 CPU 也出現自 x86 轉向 Arm 的趨勢，例如 Google 已宣布將 TPU 第八代改為連接 Axion。

#授權動能強勁與第三季財務指引
第二季授權與其他營收達到 7.73億美元，年增 50%，較預期高出約 1億美元。本季新增三份 Arm Total Access（ATA）協議，使活躍的 ATA 訂閱數突破 60 份，並新增四份運算子系統（CSS）授權。

Jason Child 解釋：「我們看到在 AI 及其持續變化的驅動下，每個人都在努力應對所有 agent 工作負載，對額外授權、不同產品變化以及不同技術的需求絲毫沒有放緩。特別是透過 ATA 和 CSS，非常有可能在未來的 12 到 24 個月轉化為設計勝出，並進一步帶來更多權利金。」

展望 2027 會計年度第三季，Arm 預期單季營收為 15.4億美元，中位數代表年增約 24%。授權與其他營收預估年增略高於 50%；權利金營收預計季增低雙位數、年增低個位數；EPS 預估為 0.56。
