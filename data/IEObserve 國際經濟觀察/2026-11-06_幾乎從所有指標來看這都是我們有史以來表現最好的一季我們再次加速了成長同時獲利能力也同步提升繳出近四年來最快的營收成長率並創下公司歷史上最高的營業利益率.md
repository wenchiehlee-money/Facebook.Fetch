「幾乎從所有指標來看，這都是我們有史以來表現最好的一季。我們再次加速了成長，同時獲利能力也同步提升，繳出近四年來最快的營收成長率，並創下公司歷史上最高的營業利益率。」

Cloudflare 共同創辦人兼執行長 Matthew Prince 一開場便點出亮眼成績，Cloudflare Q3 年化營收突破 30 億美元，單季營收達 7 億 8250 萬美元，年增 39%，淨額留存率（DNR）攀升至 122%，營業利益達 1 億 3710 萬美元，營業利益率來到 17.5%，自由現金流更達 8210 萬美元。

#第一座Agent雲：以 Isolates 技術突破傳統運算瓶頸
面對 AI 與各類自主 agent 的快速崛起，Matthew Prince 認為既有的雲端運算架構已面臨瓶頸。「傳統超大規模雲端商甚至是新興雲端商，都是圍繞著容器技術打造的。在行動裝置爆發的黃金年代，容器技術確實推動了擴充，但現在我們進入了 AI 和 agent 的時代。」

他早在前一季便預測未來五年內聯網 agent 數量將達到人類的 1000 倍，如今他認為這個轉折點會來得更快。「超大規模雲端商以容器為核心的架構，根本無法以具備成本效益的方式跟上新的 agent 典範。Cloudflare 走了一條不同的路，我們的架構建立在 Isolates 技術上，這不僅讓我們能在全球地理維度上擴展，更讓我們能以超大規模雲端商無法企及的效率實現高密度擴展。」

他明確表示：「Cloudflare 不是什麼新興雲端，也不是所謂的第四朵公有雲，我們是完全不同的定位：我們是第一座 Agent 雲端。」

#第四幕產品落地：定義 Agent 時代的網路商業新規則
隨著各家 AI 實驗室與企業大量部署 agent，現有的網路營運模式正面臨龐大衝擊。Matthew Prince 宣布，Cloudflare 已於第三季正式認列「第四幕（Act 4）」產品的首筆營收，也就是協助建立網路全新商業模式的服務。

針對這個轉變，Prince 用實際情境說明：「如果我在曼哈頓詢問我的 agent：『會議結束後今晚該去哪吃晚餐？』它可能會搜尋整個網路，瀏覽 1000 家餐廳網站並下載 1000 份菜單，但我最後只會去其中一家。這意味著有 999 家餐廳承擔了伺服器流量成本，卻完全沒有得到任何回報。」

他指出 Cloudflare 身處核心樞紐的優勢：「打造 agent 的人大多在 Cloudflare 上開發，而 agent 想抓取的目標網站也都在 Cloudflare 背後。我們正反覆扮演雙方之間的協調者。如果 agent 的流量將達到人類的 1000 倍，這需要更多頻寬與伺服器，不可能讓所有 agent 免費搭便車。」

他提到，目前的做法包括與 OpenAI 等夥伴合作優化抓取效率，在網頁內容或菜單價格變動時主動發出提示，避免無謂重複抓取；同時，未來也將發展出微型支付或以資訊交換折抵費用的新廣告模式。「如果展望未來的 10 年，我認為這將成為 Cloudflare 規模最大的業務板塊。」

#全球資安威脅海嘯：從被動防守到聯手 AI 實驗室
驅動業績表現的另一個核心關鍵，在於企業面對日益複雜的資安威脅時產生的集體焦慮。Matthew Prince 透露，AI 工具正在加速挖掘歷史程式碼中的潛在弱點。「過去幾週發布的重大安全性漏洞令人震驚，我很想說最壞的情況已經過去，但事實並非如此。」

「我們與幾乎所有領先的前沿 AI 實驗室及資安公司合作，尋找現有軟體中的缺陷。當他們發現問題時，會透過受信任的通報機制秘密告知我們，我們便會在漏洞公開前，默默為所有客戶部署好防護，無論他們是否付費。」

Prince 形容：「這就像是，住在一個每個床底、櫃子和衣櫥裡都藏著致命怪物的房子裡，而且你完全不知道牠們的存在；還是有人正徹底搜查每個角落，把怪物找出來消滅？很多漏洞早在系統中潛伏多年，現在我們正把它們清理乾淨。各地的銀行與大企業意識到這點，紛紛找上門來簽署大型合約。」

公司預估 2026 年第四季營收將達 8 億 4500 萬至 8 億 4600 萬美元，年增 38%，營業利益約為 1 億 5600 萬至 1 億 5700 萬美元；2026 全年營收預計落在 29 億 6300 萬至 29 億 6400 萬美元之間，全年營業利益預計為 4 億 6200 萬至 4 億 6300 萬美元。

#企業組織重組發酵：全力聚焦創造者與銷售者
在談及過去半年組織變革的成效時，Matthew Prince 回應了公司內部架構與 AI 應用的演變。「管理大師 Peter Drucker 曾說過，任何企業內部基本上只有三種職能：負責打造產品的人、負責銷售產品的人，以及負責衡量各項數據的人。」

「我們發現 AI 在衡量與統計各類事務上具備極高的效率與準確度。以我們投資人關係團隊為例，同仁運用自建的 agent 自動彙整所有投資人簡報、統計數據備忘錄，甚至提供財報發言稿的建議。過去每季需要大型團隊花費大量時間完成的工作，現在 agent 只要花費不到幾百美元的 token 成本就能做好，而且品質更好、錯誤率更低。」

Prince 強調，這項調整並非為了縮減整體員工規模，而是為了將資源全面轉向工程開發與第一線銷售。「我們正以前所未有的速度招募更多頂尖的人才，讓業務同仁有更多時間面對客戶，而不是填寫報表。規模化、快速創新、獲利能力與高成長並非不可兼得，而是能互相放大的綜效。」
