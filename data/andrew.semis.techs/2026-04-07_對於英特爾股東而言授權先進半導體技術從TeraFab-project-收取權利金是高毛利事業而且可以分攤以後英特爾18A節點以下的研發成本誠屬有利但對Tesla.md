# 對於英特爾股東而言，授權先進半導體技術從TeraFab project 收取權利金是高毛利事業，而且可以分攤以後英特爾18A節點以下的研發成本，誠屬有利；但對Tesla 股東而言，雖然TeraFab 建廠已邁出一步有技術來源，但未來的重重難關還是會影響Tesla未來幾年的營運現金流，獲利，及財務結構，看起來短期股價持續修正，投資人不買單，除非Cybercab/robotaxi 及Optimus 機器人量產進度能加速。

對於英特爾股東而言，授權先進半導體技術從TeraFab project 收取權利金是高毛利事業，而且可以分攤以後英特爾18A節點以下的研發成本，誠屬有利；但對Tesla 股東而言，雖然TeraFab 建廠已邁出一步有技術來源，但未來的重重難關還是會影響Tesla未來幾年的營運現金流，獲利，及財務結構，看起來短期股價持續修正，投資人不買單，除非Cybercab/robotaxi 及Optimus 機器人量產進度能加速。
