# Reuters 引述 The Information 新聞報導（Apple Considers Return to Server Market, Has Talked With Nvidia to Use Network Tech），Apple 正研究重新進入企業用伺服器市場，以 2 或 4 顆 M8 Ultra 晶片建構 AI 推理伺服器，並考慮採用 NVIDIA NVLink Fusion 連接 M8 chips。產品最早約 2029，目前仍可能取消或最終不採 NVIDIA；Reuters 無法獨立驗證。Apple 自2002年發表Xserve及2011 年停止 Xserve 產品後，若此案落地將是 18 年後重新出售伺服器產品。
