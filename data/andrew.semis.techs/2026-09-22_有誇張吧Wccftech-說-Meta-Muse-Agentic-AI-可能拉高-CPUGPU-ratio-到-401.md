# 有誇張吧，Wccftech 說 Meta Muse Agentic AI 可能拉高 CPU/GPU ratio 到 40:1

原文連結: https://www.facebook.com/andrew.semis.techs/posts/pfbid0marAd1VkRxMUsaJKbZgLsYJsVbgTYiaAU5PEp9fHizRBm69ZgQf597GgJXjjHea8l
有誇張吧，Wccftech 說 Meta Muse Agentic AI 可能拉高 CPU/GPU ratio 到 40:1

核心數字： Wccftech 說部分 agent workloads 外部估計 CPU:GPU ratio 4:1~40:1；Muse 上線前 12 日美加 iOS downloads 約 1.8m。AMD 先前已將 2030 server CPU TAM 預估上修至 >US$120bn、>35% CAGR。 

投資含義： AI Agent 不只增加 accelerator tokens，也增加 VM/orchestration/OS/tool-call CPU cycles；host CPU 可能從配角變成新的 bottleneck。 

受惠： AMD EPYC、Intel Xeon、Arm server ecosystem、server DRAM，cpu socket vendor Lotes 難怪今天都大漲。 

風險： workload architecture 差異極大，4:1~40:1 不可直接外推整體市場。但就4:1，也比市場之前預期的 1:2，1:1 好太多了吧。
