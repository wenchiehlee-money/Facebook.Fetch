#微軟（#MSFT）公布了 FY2027Q1 財報，營收年增 19% 至 923 億美元、優於預期的 907.4 億，淨利年增 32% 至 366 億，EPS 報 4.89 美元、優於預期的 4.72 美元。眾所矚目的 Azure 業務年增長加速至 48%，超越分析師預期，自由現金流也優於市場共識。微軟 Q2 營收指引優於華爾街預期，Azure 年增長將進一步加速，並重申 FY2027 依然能實現正的自由現金流，盤後上漲近 +4%。
​
📌微軟營收連六季年成長 15% 以上，其中「代理和基礎設施」報 768 億美元、年增 25%，超越市場預期的 756.3 億，主要是由 Azure 強勁增長推動，另外「設備和消費者」營收 155 億，較前一年同期下滑 3%，主要是受到 Windows OEM 及裝置業務拖累，但仍優於市場共識的 150.5 億。
​
代理和基礎設施部門中，企業雲端產品（Microsoft Cloud）銷售額年增 30% 至 639 億美元，反映了 Azure 和 Microsoft 365 Commercial Cloud 的強勁需求，毛利率報 66%，較前一年同期下滑約 2 個百分點，主要是受到產品組合向 Azure 傾斜衝擊，不過部分被雲端服務的營運效率改善抵銷。
​
☁️首度揭露的 Azure 營收達 331.7 億美元，擊敗了市場預期的 323.2 億，年增率 48%（排除匯率波動後亦同），較上一季的 42% 顯著加速，目前已經連三季加速增長，不僅超越市場預期的 44%，甚至擊敗了較樂觀預測的 47%，這是受 Azure 平台各項服務的強勁需求帶動，各類工作負載正持續成長。
​
衡量未來收入的商業預訂量（Commercial bookings）年減 12%，主要是受到去年同期大額 OpenAI 使用承諾的影響，商業剩餘履約義務（Commercial RPO）年增 73%，在強勁的 Azure 承諾下，季減幅度小於過往季節性表現。
​
💰全公司毛利率為 68%，較前一年下滑 1 個百分點，依然處於 FY2023Q2 以來的低檔，主要是受到產品組合向 Azure 傾斜、大舉建置 AI 基礎設施影響。不過營業費用控制得宜，低於財測下緣，營業利潤率報 50%，較去年同期上升 1 的百分點，兩項利潤率指標皆優於市場預期。
​
本季淨利年增 32% 至 366 億美元，優於市場預期的 350.6 億，換算 EPS 為 4.92 美元，排除投資 OpenAI 的影響則是 4.89 美元。
​
Q1 資本支出（包括融資租賃）約 452 億美元，比去年同期成長 29.5%，也高於上一季的 410 億，但遠低於市場共識的 506.7 億，其中包含了 74 億美元的融資租賃，用於購置不動產、廠房和設備（PP&E）的現金支出大約是 394 億、年增 103%。
​
資本支出增加導致 Q1 自由現金流年減 27% 至 186.3 億美元，但已遠優於分析師預期的 84.2 億。
​
👉微軟正透過整個技術堆疊（stack），為客戶提供更強大的功能、更多的選擇、更高的掌控度，以及更佳的成本效率，藉由協助企業建立並擁有自己的 AI 能力，以及透過 AI 代理的安全性與資安防護贏得信任，微軟正在將這些創新成果轉化為在各行各業持續擴大的採用規模與實際影響力。
​
Copilot 正被定位為「工作的全新作業系統」（OS for work），將 Chat、Cowork、Autopilot 與 Code 整合為統一的體驗。Copilot 日活躍用戶數季增近 50%、年增超過 5 倍，而且擁有超過 5 萬個席次的大型企業客戶數年增超過 8 倍。
​
CFO 指出，客戶對 AI 與雲端運算的需求仍持續超過微軟可用的供給容量，微軟正積極縮短新 GPU 從「到貨」到「實際上線運作」的時間（季減 20%），並透過改善晶片、模型和軟體，從現有的基礎設施中獲得更多收入，提高變現效率。
​
🎯展望未來，微軟預估 FY2027Q2 營收為 960～971 億美元，年增速約 19%，優於分析師預期的 956 億。另外微軟預估 Q2 毛利率與營益率分別為 66%、46.8%，較上一季及去年同期下滑，但是與市場預期大致相符。
​
Azure 營收年增率預估約 49%～50%（排除匯率波動後），遠優於市場預期的 45%，甚至擊敗了部分較樂觀的預測（48%）。CFO 強調，各個營運環節的效率皆有所提升，有助於抵銷部分第三方產能推遲至下半年交付所帶來的影響。
​
微軟預計 Q2 資本支出將攀升至超過 500 億美元，CY2026 全年資本支約 1,700 億美元。微軟指出，隨著 CPU、GPU，以及第三方產能交付，將推動資本支出在 FY2027 下半年加速成長，不過 FY2027 全年仍將維持正現金流。
