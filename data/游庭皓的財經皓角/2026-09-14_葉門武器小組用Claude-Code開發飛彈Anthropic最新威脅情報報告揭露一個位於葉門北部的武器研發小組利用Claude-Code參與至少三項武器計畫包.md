葉門武器小組用Claude Code開發飛彈。Anthropic最新威脅情報報告揭露，一個位於葉門北部的武器研發小組，利用Claude Code參與至少三項武器計畫，包括多級彈道飛彈、不同型號飛彈與導引火箭。

最值得注意的是，這群人並非單純拿AI查資料，而是直接讓Claude Code執行原本需要軟體工程師完成的工作，包括撰寫導引、導航與控制軟體，把開源自動駕駛系統整合進飛行電腦、調整控制參數、建置韌體與進行飛行模擬。

更驚人的是，這已經不只停留在電腦模擬，Anthropic表示，相關人員實際進行過一次導引火箭試射，雖然試射似乎失敗，但幾個小時後，他們又回頭使用Claude分析失敗原因。

這代表AI在軍事領域的角色，正從過去的情報整理、資料分析，進一步走向真正的工程研發與測試循環，目前沒有證據顯示這個小組已成功部署可實戰使用的武器，但這起事件真正值得注意的是，AI正在降低高階軍事工程，所需要的人力與技術門檻。
